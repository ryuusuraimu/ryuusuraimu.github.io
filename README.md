## About

This is the personal portfolio of Ryunosuke Nakamura (Pario), a university student and independent builder exploring product thinking, UX, iOS, e-commerce, and AI-assisted workflows.

The portfolio is built around one question:

> How can a small observation become a product that makes the next step clearer?

The site is available in English and Japanese. Use the language switcher in the header; the preference is saved in the browser.

## Latest update — July 2026

The portfolio now presents the current Anchor OpenAI Build Week chapter separately from the original Swift Student Challenge prototype. The current release candidate focuses on one-question preparation, a deterministic offline Shield, a two-minute Reset, offline QR sharing, manual Support Relay, optional Aftercare, and locally saved voice reading.

OpenAI, GPT-5.6, and Codex are described as product-design, implementation, critique, and QA partners. The hard-moment Shield remains deterministic and offline-capable; it is not presented as a generative-AI or medical product.

## Selected work

### Moftail — Shopify product lab

A Shopify and Printify brand for the US market. I use Moftail to test product-page trust, creative direction, content systems, and the operating realities of running a small store.

### Anchor — Human Signal

An iOS app for panic situations, created from a family experience and strengthened during OpenAI Build Week. Anchor makes support visible when speaking, reading, or deciding becomes difficult through prepared messages, offline QR sharing, and shortcut-based entry points.

### Shopify Theme Debugging

Turning “something feels broken” into a reproducible brief: expected behaviour, actual behaviour, impact, and likely causes.

### 365 Zen Moments

A calm, repeatable content system that keeps Moftail’s visual language coherent over time.

### StockWise

A FAQ-style knowledge search concept for beginner investors, built with React and TypeScript.

## How I work

1. **Observe** — notice the friction before reaching for a feature.
2. **Frame** — turn a vague feeling into a shared product problem.
3. **Ship** — make a small, testable version and learn from reality.

## How I use AI

AI helps me widen the field, challenge assumptions, and move from a blank page to a decision. I use several models to explore and debate, then make the final call myself. The important output is not an AI answer; it is a clearer decision with explicit constraints.

The public repository shows that workflow in a practical form: product writing, UI exploration, implementation notes, debugging, and review.

## Run locally

This is a static GitHub Pages site. No package installation is required.

```bash
cd /path/to/portfolio
python3 -m http.server 8000
```

Open <http://localhost:8000> in a browser. The page also works when opened directly, but a local server is recommended for consistent asset loading.

## Notes
